# TPanel 中英双语版（v2.2）

基于 [o-synapse/tpanel](https://github.com/o-synapse/tpanel)（原 `Orlin12/tpanel`）改造的**中英双语**版本。
原项目是运行在 Termux（安卓）或轻量 Linux 上的 Minecraft 服务端管理面板，界面为纯英文硬编码、无 i18n 机制；本版在其基础上加了一套轻量国际化层，**默认简体中文**，可一键切换英文。

## 新增 / 改动清单

| 文件 | 改动 |
|---|---|
| `public/js/i18n.js` | **新增**。中英双语语言包（各 238 条词条）+ 40 余条后端消息翻译 + `t()` / `I18N.tm()` 翻译函数 + 语言切换器组件 |
| `public/index.html` | 静态文案改为 `data-i18n` 标记；登录页、侧栏、移动端顶栏加入语言切换器；引入 i18n.js |
| `public/js/app.js` | 全部硬编码界面文案改为 `t()` 调用；toast 弹层统一走后端消息翻译；新增 `window.TP.refresh()`，切换语言后当前页即时重渲染 |
| `public/css/style.css` | 末尾新增语言切换器样式（侧栏全宽 / 登录页角标 / 移动端顶栏三种形态） |
| `server.js` | **未改动**（后端逻辑零修改，升级原版时只需替换 `public/` 目录） |

顺手修复了原项目一个 bug：`app.js` 的 `updateGauge()` 对 SVG 元素直接赋值 `className`（SVG 的 `className` 只读），改为 `setAttribute('class', ...)`。

## 界面翻译覆盖范围

- 登录 / 初始化密码页
- 侧栏导航、移动端底部导航、退出按钮
- 仪表盘（快速操作、状态卡、资源仪表、系统信息）
- 控制台（占位提示、发送按钮）
- 文件管理（列表头、工具栏、编辑器、删除/新建/上传等全部弹窗）
- JAR 管理（已安装列表、四种服务端软件介绍、版本选择弹窗）
- 服务端配置（分组标题、游戏模式/难度下拉项显示中文、保存提示）
- 备份（创建/还原/上传弹窗与提示）
- 定时任务（新建任务弹窗、动作选项、Cron 表达式参考图示）
- 设置页（全部表单标签与提示）
- **后端返回的英文消息**（如 `Server is not running.` → 「服务端未运行。」、`JAR file not found: xxx` → 「找不到 JAR 文件：xxx」）也会自动翻译成中文提示

不翻译的内容：文件/备份的实际名称、JAR 版本号、`server.properties` 的键名（这些是数据，翻译反而有害）。

## 语言切换

- 位置：侧栏底部、登录/初始化页右上角、移动端顶栏
- 点击 `🌐 中文 ▾` 弹出菜单选择语言
- 选择保存在浏览器 `localStorage`（键 `tp_lang`），刷新、重启服务后保持
- 默认语言为简体中文；如需改默认，编辑 `public/js/i18n.js` 顶部的 `DEFAULT_LOCALE`

## 运行

```bash
npm install   # 依赖已装好则跳过
node server.js
```

浏览器打开 `http://localhost:8080`，首次访问设置管理员密码即可。

## 与原版同步

后端 `server.js` 与原版完全一致；若原版更新，只需拉取新版并保留本仓库的 `public/` 目录（或把新版前端按同样方式接入 i18n.js）即可。
